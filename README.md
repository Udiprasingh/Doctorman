# 🩺 Doctorman - Doctor Searching & Healthcare Web Application

**Doctorman** is a user-friendly, multi-page web application designed to help users search for medical specialists, view doctor profiles, learn about healthcare services, and contact medical professionals seamlessly.

---

## 🚀 Features

- **🏠 Home Page (`Home.html`)**: Interactive landing page featuring doctor search functionality and quick access to core services.
- **👨‍⚕️ Doctor Directory (`Doctor.html`)**: Browse qualified doctors, view specialization details, and explore medical care options.
- **ℹ️ About Us (`About.html`)**: Learn about the platform's mission, values, and healthcare network.
- **📞 Contact Us (`Contact us.html`)**: Reach out for inquiries, support, or direct scheduling help.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic web page markup and structure.
- **CSS3**: Responsive layouts and modern UI styling.
- **Assets**: Embedded visual media for interactive user experience.

## 🌐 Overview

Finding the right doctor should be fast and simple. **Doctorman** addresses this by providing a streamlined, accessible interface where users can search for healthcare providers based on their specialties, learn about medical facilities, and send direct inquiry requests.

---

## 🚀 Key Features

- **Interactive Search Interface**: Dedicated entry points to search doctors by specialty, location, or name.
- **Doctor Catalog & Profiles**: Clear listings displaying doctor credentials, specializations, and availability.
- **Informational Hub**: Detailed background on the healthcare platform, core mission, and service standards.
- **Contact & Inquiry Form**: Built-in user forms for direct communication and appointment inquiries.
- **Responsive Layout**: Designed for seamless viewing across desktops, tablets, and mobile devices.
